# 活书 SVG 插图制作规范

适用于课程结构示意、电路、场分布、坐标曲线和软件操作图。新建活书、补课件插图或复检成品时，按原页核对、矢量重绘、重建与验收的顺序执行。

## 1. 对照原页再画

1. 保存构建前的源稿和成品。逐处清点实际占位，记录所属小节、课件文件、原页号和处理决定。页码缺失时用相邻正文、公式和图题定位，打开原页核实，必要时连看前后页。
2. 有教学图就重绘能解释该知识点的部分。图与当前位置主题不符时，把图放到对应的小节。纯文字或标题页去掉占位。原页暂时无法核实时，把缺口写入验收记录，取得证据再画。
3. 对照已验收图。只有题设、参数、端口标号和图意一致才复用，新的图注仍标本处来源。课件截图保留为本机证据。界面截图可提炼成面板、菜单路径或步骤图，并标为示意图。

## 2. 先核技术含义，再定画法

| 图类 | 绘制与核对 |
|---|---|
| 电路、结构、波导 | 核对公共节点、交叉处是否相连、开路与短路、端口编号和参考面。用连接点区分电气相连与跨线。复杂电路优先使用 Circuitikz，简单几何可直接写 SVG。 |
| 场与矢量 | 明确坐标、观察方向和截面。按右手定则核对电流、磁场与能流方向，区分入纸面 `⊗` 与出纸面 `⊙`。同一时刻的空间分布注明时刻或归一化约定。 |
| 曲线、圆图、柱图 | 按公式采样或按原图标尺读值。核对轴、单位、原点、正负、端点、极值和典型点。注明样例参数、读数精度或示意性质。多组曲线优先用 PGFPlots 或可重复运行的绘图脚本。 |
| 界面、宽表 | 保留与操作相关的窗口、字段和状态。宽表可按对象拆成竖排小块，保留原表条件、变量和单位。 |

例如，无耗平面波图应表现电场和磁场同相及方向正交，投影后的视觉比例由图中坐标决定。Smith 圆图先注明采用阻抗还是导纳坐标，再用相应归一化映射核对圆心、半径和运动方向。

## 3. 源文件与视觉约定

- 把图放到活书源工程的 `figures/`。使用稳定的语义文件名，局部重绘沿用该书的主题和构建入口。成批数值图保留生成参数或脚本，以便复算。
- 使用 `viewBox`、`role="img"` 和说明图意的中文 `aria-label`。正文图注说明教学用途并标课件名称和页码。Markdown 活书按现有语法写 `[[fig:em_boundary|切向积分环路与薄柱面（课件《媒质边界条件》第 5 页）]]`，引用名和文件名一致。
- 线条优先用 `currentColor` 和主题变量，CSS 变量用 `style="stroke:var(--fig-accent)"` 或 `style="fill:var(--fig-blue)"`。同类信息颜色统一，关键区别再加虚实线、箭头或文字，兼顾黑白打印。图注与图内文字各司其职。
- SVG 自包含，由路径、形状和文字组成。离线资源不依赖外部字体、图片或脚本。使用渐变、裁剪或箭头标记时给 `id` 加图名作用域，并检查同一资源复用后整页仍无重复 `id` 或失效引用。
- 按 390px 视口下的实际图宽布字，长标签拆行或改成上下布局。给文字、箭头和曲线极值留余量，避免标签压住导线或标记点。

## 4. 用交付成品验收

1. 运行活书项目自己的构建入口。若已有 `interactive-study-book/scripts/check_html.py`，用它检查最终 HTML，也可用项目已有的等价检查。对账正文、公式、章节锚点、测验和既有 SVG。记录源稿占位数、新增与复用数、删除项及原因。
2. 播放最终 HTML 的亮色、暗色和 390px 截图。浏览器逐图确认 SVG 已注入，检查 `getBBox()` 与 `viewBox`、字体加载后的标签位置、全页横向溢出、缺图和 JavaScript 错误。启用了延迟排版的章节滚到图处，待位置稳定再截图。自动检查通过后，逐图看连接、方向、遮挡和实际可读性。
3. 从深色模式生成实际 A4 打印稿。打印前完成 MathJax 排版，检查 `merror`、浅底深字、图文裁切以及图注是否和图处在同一页。报告按实测填写视口、页码和截图位置，并记录成品路径、大小、SHA-256 和尚未核验的项目。

## 与学习 MCP 的衔接

在接入 Review Studio 的项目中，`review_book_figures` 和 `review://book-figures` 读取已生成的图索引，供阅读计划引用图号与小节。重建后如需同步索引，用 Review Studio 仓库的 `scripts/build-book-figures.py` 从成品提取，在隔离目录先核对图注、节锚点与数量，再按已授权的部署范围处理索引。
